# LangChain Tutorials — CampusX Series

This repository contains my curated notes, practice code, and project examples while learning **LangChain** using the *Generative AI using LangChain* playlist by CampusX on YouTube.  
The goal of this repo is to help beginners understand and build **LLM-powered applications** with LangChain step by step. :contentReference[oaicite:1]{index=1}

---

## 🔎 What You Will Learn

This playlist and repository cover key concepts in LangChain and how to use them to build AI applications:

### 🚀 Core Topics
- What is **LangChain** and why use it for AI development :contentReference[oaicite:2]{index=2}  
- Understanding the **components** of LangChain like Models, Prompts, Chains, Memory, Indexes, and Agents :contentReference[oaicite:3]{index=3}  
- How to write chains and workflows using LangChain  
- Integrating Large Language Models (LLMs) for applications  
- Practical examples of building chatbots, RAG systems, and agent workflows

### 🗺 Roadmap
